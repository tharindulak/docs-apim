Do the following to try out the REST APIs with your local instance of WSO2 API Manager. 
 
   1. Expand the relevant API operation and click the **Try It Out** button.
   2. Fill in relevant sample values for the input parameters and click **Execute**.
       
       You will receive a sample cURL command with the sample values you filled in.

   3. Add the `Authorization: Bearer <access-token>` header to the cURL command. You may refer to [Getting Started Guide](../../getting-started/guide-publisher-v1.mdx) to see how to  obtain an access token with required scopes.
   
   4. Add a `-k` header to the cURL command and run the cURL command on the terminal with a running instance of WSO2 API-M.
