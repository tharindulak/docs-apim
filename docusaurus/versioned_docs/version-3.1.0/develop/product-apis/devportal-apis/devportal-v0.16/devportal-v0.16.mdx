:::warning

- The **Developer Portal v0.16 REST APIs will be deprecated in the next WSO2 API Manager release**. 
- **[WSO2 recommends that you use the Developer Portal v1 REST APIs](../devportal-v1/devportal-v1.mdx)** as it is up to date and has support for the latest WSO2 API Manager 3.1.0 features.

:::

<details>
<summary>Click here to see how to try out the APIs</summary>

Do the following to try out the REST APIs with your local instance of WSO2 API Manager.

   1. Expand the relevant API operation and click the **Try It Out** button.

   2. Fill in relevant sample values for the input parameters and click **Execute**.

       You will receive a sample curl command with the sample values you filled in.

   3. Add a `-k` header to the curl command and run the curl command on the terminal with a running instance of WSO2 API-M.

</details>
