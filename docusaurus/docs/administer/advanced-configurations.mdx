# **Advanced Configurations**

This section covers how to change and configure several features related to the advanced tenant configurations.

<Steps>

## Navigate to the Admin Portal Advanced Configuration Section {/* #step-1---navigate-to-the-admin-portal-advanced-configuration-section */}

1.  Sign in to the WSO2 Admin Portal via `https://<Server-Host>:9443/admin`.
2.  Click **Settings** --> **Advanced**.

    <a href="/api-platform/api-manager/assets/img/administer/advanced-config-browse.png"><img src="/api-platform/api-manager/assets/img/administer/advanced-config-browse.png" /></a>
    
## Change the Advanced Configurations per use case {/* #step-2---change-the-advanced-configurations-per-use-case */}

1. Change the relevant configuration accordingly and click **Save**.

    <a href="/api-platform/api-manager/assets/img/administer/advanced-config-save.png"><img src="/api-platform/api-manager/assets/img/administer/advanced-config-save.png" /></a>

    <details>
    <summary>Setting custom Linter rules</summary>

    You can add your custom rules in JSON with the key “LinterCustomRules”.

    </details>
    

2.  You can revert the unsaved changes by clicking **Cancel**.

:::tip

Before clicking **Save**, check and fix any schema validation errors visible in the editor due to the changes made.

:::

</Steps>
